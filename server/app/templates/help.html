📡 Spatika System Operations & Technical Guide

Comprehensive reference manual for the Spatika Telemetry & Health Monitoring Platform — station commands, diagnostic codes, SIM auto-detection, and system architecture.

🌐 System Navigation & User Interface

📡 DASHBOARD (Operations Center)

Single consolidated workspace. Displays system group filter tabs (KSNDMC-TRG, BIHAR-TRG, SPATIKA), real-time alarm counters, interactive station table, and bulk fleet action controls.

🚀 OTA MANAGER

Centralized firmware binary repository. Deploy new compiled .bin images to entire station groups or rollback versions with automated target verification.

☀️ / 🌙 DUAL LIGHT & DARK MODE

Toggle between dark glassmorphism mode and high-contrast light mode via the top navigation bar button. Preferences automatically persist across sessions.

⚡ 15-Command Remote Management Suite

Commands are queued on the server and delivered asynchronously during the station's next 15-minute check-in or fault report.

📊 Tier 1: Telemetry & Status DIAGNOSTICS
  • 📱 Query SIM Number (GET_NUM): Triggers 3GPP AT+CNUM & carrier USSD (*282# Airtel, *222# BSNL, *199# Jio/Vi) to auto-extract and register SIM phone number.
  • 📊 Fetch Status Now (GET_STATUS): Forces device to send complete diagnostic telemetry snapshot immediately.
  • 📍 Refresh GPS Fix (GET_GPS): Powers on GNSS receiver, acquires high-precision coordinates, updates local flash, and reports location to server.
🔄 Tier 2: Data & Reporting DATA & CALIB
  • ↑ Sync Backlog (FTP_BACKLOG): Transmits all unsent 15-minute data slots stored in internal SPIFFS flash to the FTP server.
  • 📅 Fetch Daily Log (FTP_DAILY): Prompts for a target date (YYYYMMDD) and uploads that day's complete burst log file.
  • ⏱ Reporting Interval (INTERVAL): Switch device reporting frequency between 15-Min Mode (param=15) and 24-Hr Mode (param=1440).
  • 🎛 Tip Resolution (SET_RF_RES): Configure tipping bucket rain gauge resolution to 0.25 mm (param=0.25) or 0.50 mm (param=0.50).
🛠 Tier 3: Maintenance & Queue MAINTENANCE
  • 🔒 Toggle OTA Lock: Lock station to prevent automated firmware updates or unlock for group rollouts.
  • ❌ Clear OTA Queue: Cancels pending firmware update commands for the device while leaving data commands intact.
  • 🗑 Clear All Cmds: Completely purges all pending instruction queues on server.
  • 🧹 Wipe Device Backlog (CLEAR_FTP_QUEUE): Clears local SPIFFS backlog queue file (ftpunsent.txt) to recover from corrupted memory loops.
  • 🔐 Set Wi-Fi Pass (SET_WIFI_PASS): Supervisors can remotely update station AP credential settings.
🚨 Tier 4: Danger Zone CRITICAL
  • ↺ Reboot Device (REBOOT): Gracefully shuts down modem, saves flash states, and executes hardware restart (ESP.restart()).
  • ⚠ Factory Reset (DELETE_DATA): Formats SPIFFS partition, clears non-volatile storage (NVS), and restores factory default parameters.
  • 🗑 Delete Station: Permanently purges station record and history from server database.

🔍 Diagnostic Flags & Objective Health Evaluation

📅 Meteorological Day Boundary

The data day runs from 8:45 AM (prev day) → 8:30 AM (today) — comprising 96 slots of 15 minutes each. A station achieves ✓ OK status when ≥86 records arrive on time and the 8:30 AM closing packet is confirmed.

Flag Condition Root Cause & Action
PD(X/96) 96 − Received > 10 Partial Data arrival. Intermittent GPRS coverage. Triggers automatic backlog recovery.
NDM Night Missed > 18 Night Data Missing (9 PM → 6 AM). Battery voltage drop at night. Check solar panel & battery.
CDM cdm_sts = FAIL Closing Data Missing. 8:30 AM day-closing report missed. Station was offline during window.
OFFLINE Unseen > 24.5 Hrs Station silent for over 24 hours. Hardware power failure, SIM deactivation, or antenna disconnect.
